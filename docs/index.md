# Garage Provider

Manages [Garage](https://garagehq.deuxfleurs.fr/) through its admin API v2: buckets, aliases, access keys, permissions, admin tokens and the cluster layout.

It needs Garage 2.3.0 or later, and works with OpenTofu and Terraform.

## Example Usage

```terraform
terraform {
  required_providers {
    garage = {
      source = "mathieuha/garage"
    }
  }
}

provider "garage" {
  endpoint = "https://garage-admin.example.com"
  token    = var.garage_admin_token
}
```

## What Garage does not have

Garage has no IAM: there are no users, policies, conditions or prefix-scoped grants. An access key gets `read`, `write` and `owner` on whole buckets with `garage_bucket_permission`. Public read access goes through the website endpoint (`garage_bucket.website`). Garage has no bucket policies, ACLs, versioning or object lock either.

## Operations not covered

Imperative admin endpoints are not exposed as resources: connecting nodes, skipping dead nodes, repairs, metadata snapshots, workers, block operations, purging incomplete uploads and inspecting objects. Use the `garage` CLI or the admin API for those.

### Optional

- `ca_cert_file` (String) Path to a PEM file with the CA certificates that sign the admin API certificate, added to the system pool. Can also be set with `GARAGE_CA_CERT_FILE`.
- `endpoint` (String) URL of the Garage admin API, for example `http://127.0.0.1:3903`. Can also be set with `GARAGE_ENDPOINT`.
- `insecure` (Boolean) Skip TLS certificate verification. Only for tests.
- `token` (String, Sensitive) Admin API bearer token: the `admin_token` of the daemon configuration, or a token created with `garage_admin_token`. Can also be set with `GARAGE_TOKEN`.
