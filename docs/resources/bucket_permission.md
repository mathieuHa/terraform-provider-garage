# garage_bucket_permission (Resource)

Permissions of an access key on a bucket. Garage has no policies: a key can read, write and own a whole bucket, nothing finer.

The resource is authoritative for the pair: permissions set to `false` are revoked. Destroying it revokes every permission of the key on the bucket.

## Example Usage

```terraform
resource "garage_bucket_permission" "app" {
  bucket_id     = garage_bucket.app.id
  access_key_id = garage_key.app.id
  read          = true
  write         = true
}

resource "garage_bucket_permission" "backup_reader" {
  bucket_id     = garage_bucket.app.id
  access_key_id = garage_key.backup.id
  read          = true
}
```

### Required

- `access_key_id` (String) ID of the access key.
- `bucket_id` (String) ID of the bucket.

### Optional

- `owner` (Boolean) Change the bucket settings through the S3 API (website, CORS, lifecycle) and delete the bucket.
- `read` (Boolean) Read objects and list the bucket.
- `write` (Boolean) Write and delete objects.
