# garage_key (Resource)

An S3 access key. Grant it access to buckets with `garage_bucket_permission`.

Set `id` and `secret_access_key` to import credentials that already exist, for example from another Garage cluster. They must use the Garage format: `GK` and 24 hexadecimal characters for the ID, 64 hexadecimal characters for the secret. Garage never accepts an ID again once its key is deleted, so replacing an imported key needs new credentials.

The secret is stored in the state.

## Example Usage

```terraform
resource "garage_key" "app" {
  name = "app"
}

resource "garage_key" "ci" {
  name                = "ci"
  allow_create_bucket = true
  expiration          = "2027-01-01T00:00:00Z"
}

resource "garage_key" "restored" {
  name              = "restored-from-old-cluster"
  id                = "GK31c2f218a2e44f485b94239e"
  secret_access_key = var.restored_secret
}

resource "vault_kv_secret_v2" "app" {
  mount = "secret"
  name  = "s3/app"
  data_json = jsonencode({
    access_key = garage_key.app.id
    secret_key = garage_key.app.secret_access_key
  })
}
```

## Schema

### Optional

- `allow_create_bucket` (Boolean) Allow the key to create buckets through the S3 API.
- `expiration` (String) Date after which the key stops working, in RFC 3339 format. Unset means the key never expires.
- `id` (String) Access key ID, starting with `GK`. Generated by Garage unless set together with `secret_access_key`.
- `name` (String) Human-readable name of the key.
- `secret_access_key` (String, Sensitive) Secret access key. Generated by Garage unless set together with `id`.

### Read-Only

- `created` (String) Creation date of the key.
- `expired` (Boolean) Whether the key has expired.

## Import

Import is supported using the following syntax. With OpenTofu or Terraform 1.5 and later, an `import` block with the same ID works too.

```shell
# The secret is read back, so an imported key is complete.
tofu import garage_key.app <access_key_id>
```
