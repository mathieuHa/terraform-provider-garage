# garage_bucket (Resource)

A Garage bucket with its quotas, website hosting, CORS rules and lifecycle rules.

`website` and the quotas are authoritative: removing them from the configuration disables website hosting and removes the quotas. `cors_rules` and `lifecycle_rules` are authoritative only when set: when they are absent, rules set through the S3 API are left alone, and setting them to `[]` removes every rule.

Garage refuses to delete a bucket that still contains objects.

## Example Usage

```terraform
resource "garage_bucket" "app" {
  global_alias = "app-data"
  max_size     = 107374182400
  max_objects  = 1000000

  cors_rules = [
    {
      allowed_origins = ["https://app.example.com"]
      allowed_methods = ["GET", "PUT"]
      allowed_headers = ["*"]
      expose_headers  = ["ETag"]
      max_age_seconds = 3600
    },
  ]

  lifecycle_rules = [
    {
      id              = "expire-tmp"
      filter          = { prefix = "tmp/" }
      expiration_days = 7
    },
    {
      id                                     = "abort-uploads"
      abort_incomplete_multipart_upload_days = 1
    },
  ]
}

resource "garage_bucket" "site" {
  global_alias = "www.example.com"

  website = {
    index_document = "index.html"
    error_document = "404.html"
    routing_rules = [
      {
        condition = { key_prefix_equals = "blog/" }
        redirect  = { replace_key_prefix_with = "posts/", http_redirect_code = 301 }
      },
    ]
  }
}
```

## Schema

### Optional

- `cors_rules` (Attributes List) CORS rules of the bucket. Absent means the rules are not managed by this resource; `[]` removes every rule. (see [below for nested schema](#nestedatt--cors_rules))
- `global_alias` (String) Global alias of the bucket, which is its name in the S3 API. A change adds the new alias before it removes the old one. Use `garage_bucket_alias` for additional global aliases and for local aliases.
- `lifecycle_rules` (Attributes List) Lifecycle rules of the bucket. Absent means the rules are not managed by this resource; `[]` removes every rule. (see [below for nested schema](#nestedatt--lifecycle_rules))
- `max_objects` (Number) Maximum number of objects in the bucket. Unset means no quota.
- `max_size` (Number) Maximum total size of the objects in the bucket, in bytes. Unset means no quota.
- `website` (Attributes) Serve the bucket as a static website on the Garage web endpoint. Absent means website hosting is disabled. (see [below for nested schema](#nestedatt--website))

- `created` (String) Creation date of the bucket.
- `id` (String) Bucket ID (64 hexadecimal characters).
