# garage_bucket_alias (Resource)

An additional alias of a bucket. A global alias is a bucket name visible to every key. A local alias, set with `access_key_id`, is a bucket name visible only to that key.

Do not manage the same global alias here and in `garage_bucket.global_alias`. Garage refuses to remove the last alias of a bucket.

## Example Usage

```terraform
resource "garage_bucket_alias" "legacy_name" {
  bucket_id = garage_bucket.app.id
  alias     = "old-app-data"
}

resource "garage_bucket_alias" "per_key" {
  bucket_id     = garage_bucket.app.id
  access_key_id = garage_key.app.id
  alias         = "data"
}
```

## Schema

### Required

- `alias` (String) The alias.
- `bucket_id` (String) ID of the bucket.

### Optional

- `access_key_id` (String) Access key that owns the alias. Set for a local alias, unset for a global alias.

### Read-Only

- `id` (String) `<bucket_id>/<alias>` for a global alias, `<bucket_id>/<access_key_id>/<alias>` for a local alias.

## Import

Import is supported using the following syntax. With OpenTofu or Terraform 1.5 and later, an `import` block with the same ID works too.

```shell
# Global alias: <bucket_id>/<alias>. Local alias: <bucket_id>/<access_key_id>/<alias>.
tofu import garage_bucket_alias.per_key <bucket_id>/<access_key_id>/data
```
